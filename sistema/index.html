O que foi analisado no ficheiro original

A folha DADOS_GERAIS_MEMBROS foi identificada como a base mais completa e foi usada como fonte principal (595 membros). As folhas BASE DADOS, BASE DADOS (2), BASE DADOS (ALTERAÇÃO) e BACKUP são versões anteriores/parciais da mesma listagem e continham inconsistências adicionais de género; não foram usadas como fonte de dados para evitar duplicação. Durante a leitura foram detetados e corrigidos automaticamente:

  • Capitalização inconsistente em Género, Estado Civil, Situação e Cargo (ex: "Ativo" / "ACTIVO" / "activo" tratados como o mesmo valor).
  • Faixa etária recalculada a partir da Data de Nascimento sempre que esta é válida (foram encontradas 288 faixas etárias divergentes da idade real).
  • Datas em formatos mistos (dd/mm/aaaa, dd.mm.aaaa, texto livre como "Não Batizado") normalizadas quando possível.
  • Duas datas de nascimento futuras/placeholder (idade resultante ≤ 2 anos) ignoradas por serem inválidas para um membro adulto.
  • Um par de registos com nome duplicado assinalado para verificação manual.
Estas correções foram aplicadas apenas na cópia de trabalho apresentada nesta ferramenta. O ficheiro Excel original enviado não foi alterado.

Adicionar Membros em Massa

Cole uma lista com um membro por linha. Campos separados por ponto e vírgula ( ; ), pela seguinte ordem:

Nome ; Género ; Data Nascimento (aaaa-mm-dd) ; Telefone ; Departamento ; Cargo ; Situação
Apenas o Nome é obrigatório — pode deixar os restantes campos em branco.

Carregar Base de Dados Extra

Carregue um ficheiro .xlsx, .csv ou backup .json desta ferramenta. Os membros serão adicionados à base de dados atual — nada será eliminado. Membros já cadastrados (mesmo nome) serão assinalados e ignorados automaticamente.
